Añade los dominios de clérigo del Conocimiento, la Naturaleza y la Tempestad del *Player's Handbook* de 2014 a la progresión de clérigo de 2024.

## Estado

Compatible con Foundry VTT 14.367 o posterior y dnd5e 6.0.3 o posterior. La versión 1.14.0 se verificó con Foundry VTT 14.369 y dnd5e 6.0.6.

## Requisitos

- Foundry VTT 14.367 o posterior.
- El sistema dnd5e 6.0.3 o posterior.
- El módulo oficial *Dungeons & Dragons Player's Handbook* (PHB 2024).

## Instalación

Instala el módulo desde el navegador de complementos de Foundry usando este manifiesto:

```text
https://github.com/foundryvtt-sinregistrar/dnd5e-2024-cleric-domains/releases/latest/download/module.json
```

Actívalo junto con dnd5e y el PHB 2024 en el mundo correspondiente.

## Activación y uso

El compendio nativo **D&D 2024 - Cleric Domains** contiene 19 documentos organizados en tres carpetas. Arrastra el dominio y sus rasgos al clérigo como lo harías con cualquier contenido de compendio de dnd5e.

Los rasgos se adaptan a los niveles de subclase 3, 6, 10 y 14. Algunas opciones de 2014 requieren gastar un uso de Canalizar divinidad o una configuración manual; cada caso se documenta en la nota secreta para el DJ del rasgo correspondiente.

## Actualización

Los identificadores de documentos, UUID y automatizaciones se conservan estables. Las copias importadas en actores no se sincronizan automáticamente: consulta el compendio actual para incorporar cambios posteriores.

## Contenido incluido

- Dominio del Conocimiento.
- Dominio de la Naturaleza.
- Dominio de la Tempestad.
- Automatizaciones opcionales y comprobaciones seguras de objetivos para rasgos complejos.

## Limitaciones

No todas las capacidades de las subclases de 2014 pueden automatizarse sin intervención. Las notas de DJ indican las acciones manuales necesarias.
