English

Three classic Cleric domains, adapted to the D&D 2024 Cleric subclass progression. Adds Knowledge, Nature and Tempest from the 2014 Player's Handbook as a native compendium for Foundry VTT.

Features

  • Three domains: Knowledge, Nature and Tempest, each with its associated class features.
  • 2024 progression: Features adjusted to subclass levels 3, 6, 10 and 14.
  • Native compendium: 19 Item documents organized in three folders, without overwriting the official PHB 2024 content.
  • Optional automation: Assistance for complex features with safe target checks. Some features require player or GM input.
  • Stable references: Compendium document IDs, UUIDs and automation identifiers are preserved across updates.

Requirements and installation

Foundry VTT 14.367+ (verified 14.370), D&D5e 6.0.3+ (verified 6.0.6), and the official Dungeons & Dragons Player's Handbook 2024 module (minimum 2.2.0).

  1. Install the required D&D5e system and PHB 2024 module.
  2. Install this module using the manifest URL below.
  3. Enable the module in your world and open the D&D 2024 - Cleric Domains compendium to add a domain and its features to a Cleric.

Manifest URL: https://github.com/foundryvtt-sinregistrar/dnd5e-2024-cleric-domains/releases/latest/download/module.json

Notes and translations

Some 2014 features require Channel Divinity use or manual configuration. Secret GM notes explain cases that cannot be fully automated. Actor copies already imported are not automatically synchronized after updates.

The base module is in English. For Spanish localization, use the separate Spanish translation module with Babele.

Español

Tres dominios clásicos de Clérigo adaptados a la progresión de subclases de D&D 2024. Incorpora Conocimiento, Naturaleza y Tempestad, procedentes del Player's Handbook de 2014, mediante un compendio nativo para Foundry VTT.

Características

  • Tres dominios: Conocimiento, Naturaleza y Tempestad, con sus rasgos asociados.
  • Progresión 2024: Rasgos adaptados a los niveles 3, 6, 10 y 14.
  • Compendio nativo: 19 documentos Item organizados en tres carpetas, sin sobrescribir el contenido oficial del PHB 2024.
  • Automatización opcional: Ayudas para rasgos complejos y comprobaciones seguras de objetivos. Algunas funciones requieren intervención del jugador o del DJ.
  • Referencias estables: Se conservan los ID, UUID e identificadores de automatización entre versiones.

Requisitos e instalación

Foundry VTT 14.367+ (verificado en 14.370), D&D5e 6.0.3+ (verificado en 6.0.6) y el módulo oficial Player's Handbook 2024 (mínimo 2.2.0).

  1. Instala el sistema D&D5e y el módulo oficial PHB 2024.
  2. Instala este módulo utilizando la URL del manifiesto indicada.
  3. Actívalo en tu mundo y abre el compendio D&D 2024 - Cleric Domains para añadir un dominio y sus rasgos a un Clérigo.

URL del manifiesto: https://github.com/foundryvtt-sinregistrar/dnd5e-2024-cleric-domains/releases/latest/download/module.json

Notas y traducción

Algunas funciones de 2014 requieren gastar un uso de Canalizar divinidad o configurarse manualmente. Las notas secretas para el DJ explican estos casos. Las copias importadas en actores no se sincronizan automáticamente tras actualizar el compendio.

El módulo base está en inglés. Para utilizarlo en español, instala por separado la traducción mediante Babele.
